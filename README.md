## Hi, I'm Stanislas

Software developer at [Teclib'](https://www.teclib-edition.com), the publisher of [GLPI](https://github.com/glpi-project/glpi), a free and open source ITSM and asset management software.
Based in Paris, I work on the GLPI core and on the plugin ecosystem around it.

### Focus areas

- **GLPI core**: bug fixes, features and maintenance of the main product
- **Plugins**: development, maintenance and releases of community and GLPI Network subscription plugins
- **Inventory**: native inventory, GLPI Inventory plugin and the Android inventory agent
- **Identity and access**: SSO, OAuth2 and SCIM integrations
- **Application security**: access rights checks, output escaping and input validation
